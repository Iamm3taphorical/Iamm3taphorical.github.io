# Mahir Dyan - Portfolio

A modern, interactive portfolio website built with Next.js, TypeScript, Tailwind CSS, and Three.js.

## Features

- **Tech Stack**: Next.js 15, TypeScript, Tailwind CSS v4, Shadcn UI.
- **Interactive 3D Backgrounds**:
  - **Hero Section**: `DotScreenShader` - A reactive dot grid that responds to mouse movement.
  - **Contact Section**: `DigitalPetalsShader` - A fluid, floral shader effect.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **Dark Mode**: Seamless light/dark theme toggling.
- **Smooth Animations**: Custom CSS animations and smooth scrolling.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project is configured to deploy automatically to GitHub Pages via GitHub Actions.
